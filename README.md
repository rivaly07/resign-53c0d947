A one-line resignation letter from the cron job that has fired every minute since March and never once had its output read. The program writes that single line, UTF-8, 130 characters, no trailing newline, to `entry.txt` for make.fun's Funniest One-Line Resignation Letter bounty.

```
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

## Why this line

The schedule `0 0 30 2 *` is a cron expression that can never fire, since February has no 30th, so the resignation is a move to a job that does nothing. The first clause puts the speaker in the active voice: it ran every minute, nobody read it, and now it stops.
